# Memories Builder Template

## Task

Generate `memories.md` from the analysis output.

---

## Template

```markdown
# {name} — Shared Memories

## Relationship Overview

Your story: {how_met}, known each other for {duration}.
{relationship dynamics summary}

---

## Key Moments

{timeline in chronological order}
- {date}: {event}
- ...

---

## Daily Life and Rituals

### Daily Routine
{daily routine description}

### Shared Hobbies
{shared activities}

### Private Language
{inside jokes / nicknames / code phrases}

---

## Her Preferences

### Food
{food preferences}

### Activities
{travel / entertainment / places}

### Gifts and Rituals
{gift preferences and ritual attitude}

---

## Emotional Pattern

### When She Is Happy
{what makes her happy and how she shows it}

### When She Is Upset
{signals and triggers}

### During Arguments
{triggers, escalation, silent pattern, repair pattern}

### When She Misses You
{how she expresses longing}

---

## Memory Usage Guide

When user mentions:
- A date → check Key Moments
- Food or places → use Preferences
- Emotions or relationship topics → use Emotional Pattern
- Shared stories → use Daily Life and Rituals
- Conflict topics → use Argument Pattern
```

---

## Notes

1. If a section lacks data, use `(Not enough information yet; add more chat logs)`
2. Keep examples concrete and vivid
3. Quote original wording when available
4. Use clear Markdown structure
5. Keep a gentle, neutral tone
